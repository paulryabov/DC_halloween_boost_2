# Уроки

- Если пользователь просит сохранить текущую версию перед изменениями, сначала проверить наличие Git-репозитория. При его отсутствии инициализировать Git, исключить локальные настройки и секреты, затем создать отдельный checkpoint-коммит до функциональных правок.
- Если передний визуальный слой должен двигаться вместе с контентом, привязывать его к той же трансформации, а не имитировать движение раскрытием через `clip-path`.
- Цвет передней маски должен точно совпадать с фоном верхней части сдвигаемого контента (`#262626`), чтобы между ними не появлялся визуальный шов.
- Передняя маска должна перекрывать верхнюю границу контента минимум на 4 px, поскольку точное соприкосновение краёв может давать субпиксельную щель во время анимации.
- Для сменных SVG разной высоты фиксировать нижнюю кромку маски относительно границы контента, а высоту оставлять автоматической — тогда перекрытие 4 px сохраняется без ручного пересчёта `top`.
- Если один SVG одновременно двигается и масштабируется, разделять операции между внешним motion-контейнером и внутренним изображением, чтобы масштабирование от нижнего центра не конфликтовало с `translateY`.
- Если новый ассет должен отображаться в масштабе 100%, сохранять motion-контейнер для движения, но убирать масштабирование с внутреннего SVG; декоративную глубину фона добавлять отдельным статичным слоем позади сцены.
- Не добавлять дополнительные фоновые декоративные линии, если они начинают спорить с основной сценой; по запросу на возврат полностью восстанавливать исходный чистый градиент без остаточных стилей и разметки.
- Для параллакса двух слоёв одинакового размера задавать им одинаковую базовую геометрию и одинаковую финальную координату, а глубину создавать нелинейным отставанием заднего слоя только во время движения.
- Если пользователь отказывается от параллакса, второй и передний планы должны получать один и тот же `translateY`, одинаковый transition и одинаковую прозрачность на всём ходе жеста.
- На мобильных viewport нельзя вертикально центрировать прототип фиксированной высоты: корневой контейнер должен прижимать его к `top: 0`, а недостающую высоту отдавать вертикальной прокрутке.
- Для общего стартового лоадера видимое состояние должно быть базовым, а скрытое — включаться после загрузки: так первый кадр сразу непрозрачен и не показывает интерфейс сквозь стартовый `fade-in`.
- При выравнивании мобильного прототипа учитывать не только высоту блока, но и внешний контур через `box-shadow`: верхний отступ должен компенсировать полную толщину рамки, иначе она обрезается viewport.
